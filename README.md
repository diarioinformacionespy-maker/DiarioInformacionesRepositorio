# Diario Informaciones — atención de avisos legales

Repositorio privado con el skill y las herramientas del equipo de avisos.

- `skill/diario-informaciones/SKILL.md`: reglas de atención de clientes (presupuestos, pagos, días, correos).
- `skill/diario-informaciones/scripts/`: scripts (resaltar diarios, correos KV, presupuestador, bot de Gmail, Apps Script de adjuntos a Drive, páginas del Pool y del Tablero).
- `skill/diario-informaciones/agents/`: agentes Explore y programador.
- `CLAUDE.md`: reparto de trabajo entre modelos.

Para claude.ai, el skill se empaqueta como `diario-informaciones.skill` (zip con la carpeta `diario-informaciones/`).

No subir `credentials.json`, `token.json` ni `datos_pago.json` (ver `.gitignore`).
